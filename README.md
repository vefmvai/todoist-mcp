# coach-todoist-mcp

Свой MCP-сервер к **Todoist** для агента-коуча. Даёт то, чего нет в официальном удалённом
MCP (`ai.todoist.net/mcp`): **подзадачи**, **чтение и запись комментариев** и полный
практичный набор действий поверх [unified API v1](https://developer.todoist.com/api/v1).

> Часть проекта «второй мозг» — умный помощник, который наводит порядок в делах.
> На этапе публикации для учеников репозиторий станет открытым.

## Устройство

Тонкий слой, три файла (ядро отделено от адаптеров — им же пользуются автоматизации бота):

- `client.py` — `TodoistClient`: async-обёртка над httpx к `api.todoist.com/api/v1`.
- `core.py` — функции-«кнопки» (без MCP): задачи, подзадачи, комментарии, структура.
- `server.py` — обёртка MCP (FastMCP, транспорт stdio). Точка входа `coach-todoist-mcp`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `find_tasks` | Поиск по фильтру Todoist (`today`, `overdue`, `@актив`, `no date`…) |
| `get_task` | Карточка задачи + подзадачи + комментарии |
| `add_task` | Создать задачу/подзадачу (`parent_id`, срок словами, приоритет, метки, длительность) |
| `add_tasks_bulk` | Пачка задач/подзадач одним вызовом |
| `update_task` | Изменить срок, приоритет, метки, текст |
| `complete_task` | Закрыть/переоткрыть (с пометкой авторства) |
| `move_task` | Перенести в проект/секцию или под родителя |
| `delete_task` | Удалить (только с `confirm=true`) |
| `quick_add` | Создать одной строкой на естественном языке |
| `get_comments` / `add_comment` | Комментарии к задаче — читать и писать |
| `get_structure` | Проекты + секции + метки одной картой |
| `manage_structure` | Создать проект / секцию / метку |
| `completed_history` | История завершённых задач за период |

## Запуск

Нужен персональный токен Todoist (Settings → Integrations → Developer) в
переменной окружения `TODOIST_API_TOKEN`. Токен личный — **в репозиторий не кладём**.

```bash
export TODOIST_API_TOKEN=xxxxxxxx
uv run coach-todoist-mcp        # или: python -m coach_todoist_mcp.server
```

### Подключение к Claude Code (мак)

Токен берётся из Keychain обёрткой `~/.claude/scripts/todoist-mcp.sh`, сервер
регистрируется в `~/.claude.json` → `mcpServers`. Подробности — в документации проекта.
